
# 📚 Library Management System (LMS) Using C

## Overview

The Library Management System (LMS) is a console-based application developed in C that automates core library operations such as book management, searching, issuing, returning, and maintaining records through file handling.

The system enables librarians to efficiently manage books and users while ensuring accurate issue and return tracking with automatic date management.

---

## Features

### Book Management

* Add New Books
* Update Existing Book Details
* Remove Books
* Search Books
* View Complete Catalog

### Transaction Management

* Issue Books
* Return Books
* Automatic Due Date Tracking
* List Issued Books

### Data Management

* File-Based Data Storage
* Persistent Records
* Book Database Management
* Issue History Tracking
